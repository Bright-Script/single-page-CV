# Single Page CV

A simple, responsive one-page CV built with plain HTML and CSS.

Project idea: https://roadmap.sh/projects/single-page-cv

## Files

- `index.html` – the CV content
- `style.css` – colors, fonts and responsive layout
- `README.md` – this file

## Fonts

Only fonts already installed on your computer are used (Segoe UI, Roboto, Helvetica, Arial, Georgia). Nothing is loaded from the internet.

## How to run

**Option 1 – Open directly**

1. Put `index.html` and `style.css` in the same folder.
2. Double-click `index.html` to open it in your browser.

**Option 2 – Run on localhost**

1. Open a terminal in the project folder.
2. Start a local server (Python is enough):
   ```bash
   python -m http.server 8000
   ```
   (use `python3` instead of `python` on Linux/macOS if needed)
3. Open http://localhost:8000 in your browser.
4. Press `Ctrl + C` in the terminal to stop the server.

**Option 3 – VS Code**

Install the *Live Server* extension, right-click `index.html` and choose **Open with Live Server**.

## Tip: save as PDF

Press `Ctrl + P` in the browser and choose **Save as PDF**. The print styles keep it clean.
